# 开始使用 N.E.K.O RimWorld

你可以在 N.E.K.O 对话中询问殖民地情况，再到插件面板阅读完整建议和历史讨论。插件只读取游戏信息、提供建议，不会替你下达游戏命令。

需要安装 RimWorld Bridge Mod、Harmony 和 N.E.K.O RimWorld 插件，并准备一个 OpenAI 兼容的模型服务。安装位置和可用宿主版本以所用安装包的说明为准；当前源码仍在首发准备中，没有新发布包。

## 连接游戏

1. 在游戏 Mod 列表中启用 Harmony 和 N.E.K.O RimWorld Bridge，按游戏要求重启。
2. 打开游戏的 Mod 设置，进入 **N.E.K.O RimWorld Bridge**，勾选 **Enable local N.E.K.O bridge**。
3. 点击 **Generate new pairing token** 生成配对码，记下端口和配对码，并退出设置让游戏保存。
4. 在 N.E.K.O 插件管理中启动 RimWorld 插件，打开面板的**设置**，填入相同端口和配对码，点击**保存并应用连接设置**。
5. 载入要咨询的殖民地。面板显示**游戏已连接**后，可在连接检查页读取一次殖民地概况；这个检查不调用模型。

配对码输入框留空会保留原值。游戏端重新生成配对码后，需要在插件端同步修改。插件默认不自动启动，下次使用前请确认它已经启动。游戏暂停时也可以咨询。

## 配置模型

在**模型服务**中填写服务地址、模型名称和所需 API key，点击**保存模型设置**。通常可以保留高级设置的默认值。

RimWorld 咨询使用这里配置的独立模型，不会自动继承 N.E.K.O 角色的模型配置。咨询会向该服务发送相关游戏信息，可能产生费用。保存设置、查看历史和检查游戏连接不会调用模型；“已配置”也不等于已经验证模型服务可用。

密钥留空会保留原值。已保存的密钥不会回填到页面，未保存的密钥也不会写入浏览器存储。

## 理解保存结果

- **正在保存**：可以切换本面板页面，等待同一次操作的结果，不用再次点击保存。
- **设置已保存并应用**：已收到保存确认，或已重新读取配置核对一致，并已应用到插件。
- **没有应用**：根据提示检查输入，再决定是否重试。
- **尚未确认**：不能确定是否已经写入。输入仍保留，可核对同一次保存的状态。若插件已重载，请先检查当前配置，再决定是否重新保存。

保存结果不明时不会自动重复写入，也不会显示已经保存。关闭或重载插件可能中断保存；回执只在当前插件运行期间保留，最多保留 20 次。

## 提问与阅读

回到 N.E.K.O 对话，可以问：“帮我看看 RimWorld 里，现在最该先处理什么？”

**最近建议**展示当前殖民地最近一次讨论的短答，点击**查看完整回答**展开全文，也可以直接复制。分析期间可以切换面板页面；停止或重载插件会中断咨询。旧建议仍属于原讨论，不会因为游戏继续运行而自动更新。

**历史记录**可以按问题或对话角色查找，也可以只看当前殖民地。要继续讨论，回到同一角色的 N.E.K.O 对话，提及原问题或相关人物。读取和刷新历史不会重新咨询。

**调试**中保留执行记录、原始读取和咨询测试。咨询测试会调用模型；游戏连接检查不会。两种操作分别标明，不会因为浏览页面而自动执行。

## 没有得到完整结果时

先阅读页面给出的原因。回答未完成、历史保存未确认和文件导出失败会分别说明。没有可下载文件时，已保留的正文仍可阅读或复制；不要仅为保存回答而重复咨询。

需要进一步核对时，打开该回答的高级诊断。保存的内容只代表当时的游戏情况；离线时仍可查看历史。面板目前提供简体中文和英文，中文变体使用简体中文，其余未支持的语言回退到英文。
